CrossImpactBalances.jl

Julia implementation of Cross-Impact Balance (CIB) scenario analysis — a methodology for finding the internally consistent futures of a qualitative multi-descriptor system from an expert-elicited cross-impact matrix.

This package is a reimplementation of the Python sei-international/cibsa library with a memoized basin-of-attraction analysis and a threaded exhaustive search. The benchmark suite (test/benchmark.jl) routinely reports 25–100× speedups over the Python reference.

Installation

using Pkg
Pkg.add(url="https://github.com/IainDM/CrossImpactBalances.jl")

find_consistent and find_basins always search the whole scenario space. For multi-threaded search, start Julia with multiple threads:

julia -t auto --project=.

Quick start

using CrossImpactBalances

cib = load_scw("path/to/CIB_global.scw")

# Each consistent scenario
for u in cib.consistentScenarios
    println("sig=", signature(cib, u))
    for (i, desc) in enumerate(cib.descriptors)
        println("  ", desc, " = ", cib.variants[desc][u[i] + 1])
    end
end

# Exhaustive basin-of-attraction analysis
fixed_points, basin_sizes, cycle_count = find_basins(cib)

For more, see the examples/ folder in the repository and the API reference.
